# Content enrichment v6.1 (사건 프로필 보강)

결과가 일부 인물에 몰리는 문제를 줄이기 위해, **본문에 기록된 행동만** 비교 신호로 추가했다. 분포를 강제로 균등화하지 않았다. 모든 항목은 여전히 검수 전 초안이다.

## 변경 요약

- 사건 프로필 251 → 265개 (대표 자격 156 → 165)
- 매칭 가중치: cos 0.35→0.50, behavior 0.25, coverage 0.20, specificity 0.20→0.05 / 규칙 보너스 +3→+2 (상한 ±5 유지)
