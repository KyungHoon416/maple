# Product spec (확정 구현)

**정책**: 로그인·회원가입·개인정보 입력 없음, 무료·무제한, 응답은 메모리+sessionStorage(`mfs-session-v6`)만. 재검사/탭 종료 시 삭제. 외부 요청은 Google Fonts와 (ZIP 생성 시에만) cdnjs JSZip.

## 화면 (해시 라우팅 — Artifact 제약상 `#name` 형식)
| 경로 | 화면 | 비고 |
|---|---|---|
| `#` | 인트로 | 안내 문구 3종, 등급 예시 카드(예시 표기), 4단계, 사전 링크 |
| `#test` | 검사 | 1문항씩, 라디오 2개, 진행률, 이전/다음, 미응답 시 다음 비활성, 마지막 제출 중복 방지 |
| `#reveal` | 카드 공개 | 카드 뒷면→탭/Enter 뒤집기(0.9s), 건너뛰기, reduced-motion 즉시 공개 |
| `#result` | 결과 | 카드, 등급 안내, 근거(문항↔장절), 6축 차트+실제 선택, TOP3, 강점/질문, 말씀, 실천 3, 기도, 저장/공유 |
| `#cards` | 카드뉴스 | 7장, 피드/스토리, 이전/다음·점·키보드·스와이프, 현재/선택/전체 ZIP 저장, 텍스트 대체 |
| `#characters` | 인물 사전 | 전체/구약/신약, 이름 검색, 24개씩 페이지 |
| `#character-<id>` | 인물 상세 | 사건·장절·자격·검수 상태 |
| `#share-<id>-e<n>` | 공개 공유 | 인물·사건 소개만, 개인 결과 없음 |
| `#about` | 소개·FAQ | 기준·한계·등급표·개인정보·저작권·이미지 |

## 예외
- 결과 없이 `#reveal/#result/#cards` → “아직 완료된 검사가 없어요” + 시작/이어하기
- 구버전(10문항) 세션 → 초기화 + 안내(마이그레이션하지 않음)
- 새로고침 → 같은 응답으로 재계산(결정론, 재추첨 없음)
- 다시 검사 → 페이지 내 확인 대화상자 후 삭제
- 저장: Artifact 안에서는 `downloads` capability로 확인창, 일반 브라우저는 `<a download>`. 실패/거절 시 토스트
- 공유: Web Share(파일) → 미지원 시 안내, 카카오 키 미설정 → 문구 복사, 공개 URL 미설정 → URL 없이 소개 문구만 복사
