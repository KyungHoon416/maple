# Card rarity spec (rarity-2, 2026-11-25)

## 결정 사항
- 사용자 결정: 등급은 **특기 조합의 설계상 희귀도**로 정하고 6단계로 세분화. 능력치(성향)는 카드에 따로 표시하며 등급에 반영하지 않음.
- 포켓몬 카드 고유 용어(AR, SAR, ACE SPEC, ex/GX/V, MUR)는 쓰지 않고, 일반적인 단계 이름과 자체 특별판 이름을 씀.

## 등급 (CONFIG.rarityGrades)
signatureKey = `대표 특기 | 다른 계열 보조 특기 계열(없으면 none) | 사건 상황 유형`. 4,096개 동일 가중치 응답 조합에서 그 키가 대표 카드로 나온 횟수(patternCount)로 등급을 정함. 실제 이용자 비율·뽑기 확률이 아님.

| 등급 | 이름 | patternCount | 키 수 | 조합 수 | 마감 |
|---|---|---|---|---|---|
| C | Common | 200 이상 | 4 | 990 | 아이보리 무광 |
| U | Uncommon | 90~199 | 13 | 1,726 | 브론즈 |
| R | Rare | 40~89 | 15 | 947 | 세이지·은 광택 |
| RR | Double Rare | 16~39 | 11 | 290 | 세이지 + 안쪽 금선, 작은 별빛 |
| SR | Super Rare | 6~15 | 10 | 93 | 금빛, 별빛 |
| UR | Ultra Rare | 1~5 | 20 | 50 | 무지갯빛 홀로그램 + 스테인드글라스 |

## 특별판 (등급과 별개, 등급·인물·특기는 바뀌지 않음)
- **SA 스토리 아트**: 해당 사건의 장면 일러스트(`window.MFS_SCENES`)가 있을 때. 현재 장면 일러스트 0장이라 아직 나오지 않음.
- **P 프로모**: 성탄(12/18–1/6), 고난주간~부활절 후 7일에 받은 카드에 기념 표시. 날짜에 따라 표시만 달라짐.

## 능력치 (카드 하단 6칸)
6개 영역에서 고른 방향: A 2개 → A 짧은 이름, B 2개 → B 짧은 이름, 하나씩 → ‘균형’. (신앙: 기도·이해 / 행동·순종, 말씀: 묵상 / 실천·나눔, 기도: 솔직함 / 꾸준함, 예배: 경청·기억 / 찬양·실천, 성찰: 다시 시작 / 깊은 숙고, 공동체: 공감·대화 / 도움·숙려). 점수·별점·높고 낮음 없음.

## 검증
`npm run generate:rarity` → 6등급 모두 존재. `npm run test:exhaustive` 실패 0. 문항별 A/B 선택 시 SR·UR 비율은 `qa-exhaustive.json` optionBias에 기록. 프레임 픽스처: `docs/screenshots/fixture-rarity-frames-6.png`.
