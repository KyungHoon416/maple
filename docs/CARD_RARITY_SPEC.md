# Card rarity spec (rarity-1)

- **특기**: 34개 = 조합 특기 10(두 문항 신호 필요) + 신호별 기본 특기 24. 대표 특기는 “사용자 선택 ∩ 대표 사건 신호”에 필요한 신호가 모두 있는 첫 조합 특기, 없으면 사건에서 가장 먼저 기록된 일치 신호의 기본 특기. 보조 특성 = 나머지 일치 신호의 기본 특기(최대 3).
- **signatureKey** = `대표 특기 | 다른 계열의 보조 특기 계열(없으면 none) | 사건 상황 유형`. 원시 응답·식별자 미포함.
- **patternCount**: 4,096개 응답(동일 가중치 QA 공간)에서 그 키가 대표 카드로 나온 횟수. 실제 이용자 분포·뽑기 확률이 아님.
- **임계값**: N ≥ 129 · R 33~128 · SR 9~32 · SSR 1~8 (`CONFIG.rarityThresholds`).
- **현재 결과**: 키 44개 — N 13 / R 7 / SR 12 / SSR 12. 조합 수 기준 N 3,271 · R 613 · SR 179 · SSR 33 (합계 4,096, 카드 없음 0). 상세: `RARITY_DISTRIBUTION.csv`, 인물별 등급 분포: `QA_DISTRIBUTION.csv`.
- **편향 점검**: 문항별 A/B 선택 시 SR·SSR 비율 2.9%~7.5% 범위(`qa-exhaustive.json` optionBias). 특정 방향에 등급 보상을 주는 규칙은 없지만, 조합 구조상 문항별 차이가 존재함.
- 한 번 답을 바꿨을 때 등급이 바뀌는 비율 19.3%, 대표 인물이 바뀌는 비율 45.5% (49,152 이웃 비교).
- 같은 인물도 특기 조합에 따라 등급이 달라짐: 4,096 공간에서 6명이 2개 이상 등급으로 등장(예: 다니엘 N 256 · SR 14, 엘리야 N 52 · R 121). 인물 고정 등급 없음.
- 프레임: Canvas — N 아이보리/브론즈, R 세이지/은색 광택, SR 금빛+별빛, SSR 무지갯빛 홀로그램+스테인드글라스. 등급은 글자로도 우하단 표기, 카드 번호 `OT-016-02` 형식(인물 코드+사건 번호).
