# Manual QA checklist (실기기 — 미실행)

이 환경에는 실기기가 없어 아래 항목은 **검증하지 않았다**.

- [ ] iOS Safari: 카드 저장 → 다운로드/파일 앱 경로, 7장 ZIP 메모리, 카드 뒤집기, 스와이프
- [ ] iOS Safari: Web Share 파일 공유(HTTPS 배포 후)
- [ ] Android Chrome: PNG 저장, Web Share, 뒤로가기
- [ ] 카카오톡 공유(키·도메인 등록 후), 공유 메시지 썸네일
- [ ] Claude 앱(iOS/Android)에서 Artifact 열기 → downloads 확인창
- [ ] 스크린리더(VoiceOver/TalkBack): 문항 라디오, 카드 alt, 차트 desc
- [ ] 200% 확대, 가로 모드
- [ ] 저속 네트워크에서 웹폰트 지연 시 캔버스 글꼴(3.5초 후 대체 글꼴)
