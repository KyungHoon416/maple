# MY FAITH STORY — project rules (v6.0 spec summary)

- Korean self-reflection web app 「나의 믿음은 누구를 닮았을까?」. Static, no backend.
- **Never** add login/sign-up/social login/Firebase Auth/member DB/my page, or ask for name/email/phone/church.
- Answers stay in memory + sessionStorage only. Exception, opt-in only: the 7-day plan (src/plan.js, #plan-<id>-e<n>) may save its slug, start date and checked days in localStorage when the person turns "이 기기에 진행 상황 저장" on; turning it off deletes it. Plans are built from public character/event data, never from answers. No server, analytics, external AI, logs or URLs carry answers, charts or scores. Share links = public character/event pages only.
- 12 questions, exactly A/B, no right answer. 6 areas × 2 questions, 24 trait tags (6 unmeasured → excluded, not zero).
- 100 characters (OT 50 / NT 50). Jesus/God are never candidates. Negative-event characters (Cain, Judas, Saul, Ananias & Sapphira) are reflection/library only.
- Matching engine is a pure, deterministic function (src/engine.js). No per-option character mapping, no randomness, no LLM.
- Rarity C/U/R/RR/SR/UR (6 tiers, CONFIG.rarityGrades, rule rarity-2; user decision 11/25) = design rarity of signatureKey (skill | secondary family | event context) over the 4,096 equal-weight combos. Not faith level, not probability. Never hand out rarity by "good" answers or by "ability scores" (user chose this explicitly). Cards also show 능력치 = the chosen tendency per area (e.g. 기도 솔직함/꾸준함/균형), never ranked. Special editions, separate from rarity: SA (story-art scene image exists, window.MFS_SCENES) and P (promo mark during Christmas Dec 18–Jan 6 and Holy Week–Easter+7). Do not copy Pokémon-specific grade names (AR, SAR, ACE SPEC, ex/GX/V, MUR). Regenerate with `npm run generate:rarity` after any data change.
- Never hardcode mock scores (베드로 88 / 다윗 81 / 모세 74).
- Do not claim generated illustrations, human content review, deployment or tests that did not happen. Portraits: 50 generated (public/assets/characters/*.webp, list baked by build), the rest show a placeholder (watercolor landscape + name medallion, labelled 일러스트 준비 중). Add new portraits via scripts/fetch-portraits.sh + WebP conversion, then `npm run build`.
- Quiz option art: 24 dedicated Canva-generated illustrations (anonymous people; public/assets/options/Qnn-X.webp, list baked by build). Canva exports can come back with added text — check every export by eye before use.
- Event scene art: Canva-generated watercolor scenes for the most frequent primary-result events (public/assets/events/<eventId>.webp 960×640, list baked by build as window.MFS_SCENES; prompts in scripts/portrait-prompts.js SCENES; download via scripts/fetch-scene.sh, crop overrides in scripts/process-images.py). Jesus and God are never drawn as figures (implied only); reject drafts that show them, blank faces or added text. A scene image makes the card an SA edition and replaces the 임시 일러스트 on card-news slide 4.
- Quiz: tapping an option auto-advances (user request, overrides spec §3).
- Hosting: Firebase project my-faith-story → https://my-faith-story.web.app. `npm run build:hosting` writes hosting/ (committed; CI deploys it). Share links = /share/<id>-e<n> static pages with OG tags. Rebuild hosting/ after any data or portrait change.
- Workflow: `npm run generate:rarity && npm run validate:data && npm test && npm run test:exhaustive && npm run build && npm run test:e2e` (= `npm run qa`).
